# Tagasiside

Two plain HTML/JS pages and a Node.js server using one MariaDB table.

1. Create a MariaDB database named `tagasiside` and import `database/schema.sql` into it. The supplied schema replaces the table, so import it only during initial setup.
2. Copy `.env.example` to `.env` and set your database credentials.
3. Run `npm install`, then `npm start` (Node.js 20.6+).
4. Open http://localhost:3000 for the form or http://localhost:3000/opetajavaade.html for all scores.

First name, surname, group and an integer score from 1–5 are required. Comment is optional. Text fields allow up to 255 characters. The ID is generated by MariaDB. There is no login; all scores are visible to anyone with access to the server.

Run `npm test` for input validation checks.
