# Tagasiside

Two plain HTML/JS pages and a Node.js server using one MariaDB table.

Install Node.js 20.6+ (includes npm) and Docker Desktop. Start Docker Desktop, then run these commands from the project folder.

Start MariaDB (port 3307 avoids conflicts with an existing local database):

```sh
docker run -d --name tagasiside-db -e MARIADB_ROOT_PASSWORD=change-me -e MARIADB_DATABASE=tagasiside -p 127.0.0.1:3307:3306 -v tagasiside-data:/var/lib/mysql mariadb:11
```

Wait until this command succeeds; if it reports that the database is not ready, retry it after a few seconds:

```sh
docker exec tagasiside-db healthcheck.sh --connect --innodb_initialized
```

Import the table **once during initial setup**. The supplied schema replaces the table and deletes any existing scores:

```sh
docker exec -i tagasiside-db mariadb -uroot -pchange-me tagasiside < database/schema.sql
cp .env.example .env
```

In `.env`, change `DB_PORT` to `3307`. The remaining example values match this Docker setup:

```dotenv
DB_HOST=127.0.0.1
DB_PORT=3307
DB_USER=root
DB_PASSWORD=change-me
DB_NAME=tagasiside
PORT=3000
```

The password above is for local development. If you change it, use the same value in the Docker command, import command and `.env`.

Install dependencies and start the app:

```sh
npm ci
npm start
```

Open http://localhost:3000 for the form or http://localhost:3000/opetajavaade.html for all scores. If port 3000 is in use, change `PORT` in `.env` and use that port in the URL.

To stop, press Ctrl+C in the app terminal and run `docker stop tagasiside-db`. To run again:

```sh
docker start tagasiside-db
npm start
```

Wait for MariaDB to be ready before submitting scores. The Docker volume keeps scores between restarts; do not reimport the schema.

If MariaDB is already installed directly, Docker is optional: create a database named `tagasiside`, import `database/schema.sql` once, and set `.env` to your database's host, port and credentials.

First name, surname, group and an integer score from 1–5 are required. Comment is optional. Text fields allow up to 255 characters. The ID is generated by MariaDB. There is no login; all scores are visible to anyone with access to the server.

Run `npm test` for input validation checks.
